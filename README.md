# Programming 1A Project 1 - Chat App

This repository contains my Programming 1A Project 1 Chat App.

The application was developed using Java and Apache NetBeans.

## Project Features

- User registration and login.
- Username and password validation.
- Cell phone number validation.
- Sending and storing messages.
- Disregarding messages.
- Generating message IDs and message hashes.
- Displaying stored messages.
- Searching and deleting stored messages.
- Unit testing using JUnit.

## Technologies Used

- Java
- Apache NetBeans
- JUnit
- GitHub
